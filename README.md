# AI-Powered Product Assistant

A Django product catalog that uses Ollama to generate an INR price for every
new product and a description when the seller leaves that field blank. A
seller's provided description is preserved. Existing products retain their
original USD currency.

## Setup

1. Create and activate a virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Install and start [Ollama](https://ollama.com/), then download the model:
   `ollama pull qwen2.5:3b`.
4. Optionally configure `OLLAMA_BASE_URL` (defaults to
   `http://localhost:11434`) and `OLLAMA_MODEL` (defaults to `qwen2.5:3b`) in
   `config/.env`. Django loads this file when the project starts; process
   environment variables take precedence.
5. Run `python manage.py migrate`.
6. Start the server with `python manage.py runserver` and open
   `http://127.0.0.1:8000/`.

The product price is generated by AI and is not editable in the submission form.
If the AI service is unavailable or returns invalid data, the form displays an
error and does not save the product.

Product images are optional. Uploaded images are stored under `media/products/`
and served from the media URL during development.

Run tests with `python manage.py test`.
